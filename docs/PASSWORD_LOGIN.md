# 今晚可用版：默认 Magic Link 首次验证，之后邮箱＋密码

本版本基于已合并的 PR #6。无需购买 SMTP、无需升级 Supabase、无需编辑任何邮件模板。不执行项目 SQL，不改 RLS 或资产数据。

## 现有邮箱第一次设置密码

1. 部署本次分支后，打开正式网站 `/auth/login`。
2. 点击 **Magic Link 备用**，输入你原来使用的同一个邮箱，点击一次“发送登录邮件”。这只尝试登录已有用户，明确禁止自动创建用户。
3. 用发起登录的同一浏览器、同一域名打开 Supabase 默认邮件中的链接。保留 PR #6 的 PKCE callback 和 Cookie 修复，不要求自定义模板或数字验证码。
4. 登录成功后，在工作台打开“项目与云端设置” → **账号安全 · 设置密码**，或直接访问 `/auth/security`。
5. 输入两次相同的新密码，点击“保存密码”。至少 12 个字符，总长不超过 72 个 UTF-8 字节；空格不自动去除，建议使用密码管理器生成独立密码。
6. 网站重新向 Supabase `getUser` 验证当前会话和 `email_confirmed_at`。只有已登录且邮箱已验证的非匿名用户可以继续，然后调用当前用户的 `updateUser({password})`。
7. 页面显示成功后，Mac、Windows、手机均可用原邮箱和新密码登录。不需重建账户，不改变 user ID，原有项目仍归属于同一用户。

已经有有效、已验证邮箱的登录会话时，可以直接从第 4 步开始。没有有效会话时不能直接设置密码，必须先完成身份验证。

## 日常登录

默认标签是 **邮箱＋密码**，调用 `signInWithPassword`，不会发送登录邮件。Cookie 仍由 PR #6 的 SSR 客户端处理。多个设备分别登录同一账号，各自持有会话。

登录成功不会自动推送、初始化或覆盖项目。换设备后仍按现有操作手动载入云端项目。

## 错误和重新认证

- 邮箱或密码不正确：停留在登录页，显示通用提示，不重新注册用户，不自动发送邮件。
- 首次尚未设置密码：先用 Magic Link 登录，再设置密码。应用不通过身份表或错误差异猜测“账号是否存在/是否有密码”。
- 邮箱尚未验证：设置页面与服务端写入接口都会拒绝，不依赖客户端隐藏按钮作为安全措施。
- 两次密码不一致或不满足长度：拒绝提交，服务端也会复查。
- Supabase 返回 `reauthentication_needed` / `reauthentication_not_valid`：不继续更新，显示“重新认证（Magic Link）”入口。先手动重新登录，再返回设置页面；不关闭 Supabase 的安全选项，也不会自动申请认证邮件。
- 如果提供商仍要求额外 nonce 验证，本版会保持拒绝，不尝试绕过；请保留错误信息继续排查。本版优先提供近期 Magic Link 登录后设置密码的简单流程，没有新增复杂的 nonce 邮件界面。
- 忘记密码：使用同一邮箱的 Magic Link 登录后进入账号安全设置新密码。无需单独的自定义恢复邮件模板。
- 免费邮件限流仍存在：等待额度恢复后再发一封；密码登录本身不会使用发信额度。不要因为首次发信受限就删除用户或新注册另一个账号。

## 后台只需要确认这些设置

**Supabase**：Email 登录保持开启；保留现有默认邮件模板；Site URL 为正式网站；Redirect URLs 包含 `https://framework-studio-psi.vercel.app/auth/callback`。不关闭邮箱确认，不修改 RLS，不执行 SQL。

**Vercel**：沿用 PR #6 的 Supabase URL / Publishable Key 与正确的站点域名，部署本次修复分支。无需 SMTP 或 Service Role Key，不新增收费配置。

本次没有连接生产 Auth 服务，不会替你设置真实密码；真实密码由你部署后在 HTTPS 页面中亲自输入并提交。Supabase Auth 存储其密码凭据，应用不把密码写入项目 JSON、localStorage、日志、Git 或数据表。设置请求只含密码与确认值，不接受目标 user ID / 邮箱。

## 验证范围

`npm test`、`npm run test:auth:e2e`、`npm run build`、`npm run typecheck`。

登录集成使用本地回环 Auth 替身，不发送真实邮件，不改真实密码。验证默认邮件 PKCE 登录、两次密码确认、当前用户更新、另一设备密码登录、错误密码、未登录/未验证拦截、重新认证提示，以及注册/删除/项目数据库请求计数均为 0。真实 Safari/Windows/手机、Supabase 账户安全设置和邮件送达仍需部署后低频验收。
