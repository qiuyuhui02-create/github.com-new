后续手动工作流优化基于已合并本版的 main，详见 [MANUAL_WORKFLOW.md](MANUAL_WORKFLOW.md)。当前无需再次处理旧版 PR 的合并顺序，不启用 PR #9。

本 PR 在现有项目和当前 main（已合并 #6、#7）上迭代。开发分支合入 #4，包含 #3 的完整依赖和跨平台素材索引；#5 的真实 AI 调用与配额 SQL 不引入，三栏结果改为手动粘贴。保留既有登录与云端读写代码，所有核心功能均可未登录使用。无需新增环境变量、信用卡、SMTP 或 SQL。

## 今晚如何上线

1. 先在**原 Vercel 正式网址、原 Mac Safari**导出当前 JSON 备份，单独保存到安全位置（预览域名与正式域名的浏览器存储相互独立）。不要清除网站数据。
2. 查看本 PR 的 Vercel Preview，验收新页面。Preview 内请导入备份副本；它无法直接读取正式网站的本地数据。
3. 确认通过后由你手动合并此整合 PR，Vercel 沿用现有项目和网址自动部署 main。无需重建 Vercel 项目。
4. 本 PR 已包含 #3、#4 的提交，不需要先逐个合并旧 PR。#5 暂缓，不能再整包合并其旧版付费/试用 API 路径；未来需重新基于最新 main 整理。不要执行 hybrid-storage.sql 或 ai-quota.sql。
5. 不需要 Supabase 操作或登录；今晚不再发送测试邮件，也不部署任何生产数据库变更。

## Mac 的五个核心工作区

- **创作日程**：月历、任务日期/时间/地点/类别/状态/备注、历史编辑、项目名与截止倒计时；主动工时计时、手动补录/修改、今日和本周统计；每日心情和私人创作日记。
- **剧本工作台**：中文/日文剧本按场景组织，保留只读原稿；三个手动 AI 栏支持整版/逐段采用，人工候选确认后才写入独立定稿；工作稿、AI 结果和定稿可留版本，剧本变更提示分镜复核。
- **资产库**：人物/场景/道具/服装/其他，设定、版本、制作状态（已完成表示正式确认）、小缩略图与参考图。既有编号和关联沿用。上传图片只在浏览器读取并生成最长边 800px、单张不超过约 260KB 的预览，不上传原图。
- **分镜工作台**：镜号、画面参考图、景别、构图、机位、运动、时长、画面说明、对白、声音、状态与资产关联；可从剧本定稿生成文字草稿。
- **视频提示词与制作**：每镜独立任务，Prompt、复制、首尾帧/参考清单、目标时长/比例/运动/模型/状态、生成版本、失败和修改意见；相对路径登记可选。网站不生成或上传视频。

Windows 完全可不打开网站：素材自行通过微信/其他工具传输。已有本地素材库保留为可选工具，未连接原件显示“素材未连接”，不要求 Mac 具备 NTFS 写权限，也不会自动扫描 SSD 或改写原文件。

## Mac → 手机快照

1. 在 Mac 点击 **导出项目**，得到带时间戳文件名的 JSON。快照包含日程、心情日记、工时、剧本及手动 AI 栏、资产索引/版本、分镜、所有 Prompt 和已生成的小缩略图。
2. 将 JSON 通过 AirDrop、微信或自己的文件传输方式保存到手机“文件”。JSON 含私人日记，请只发送到自己的设备。
3. 手机打开**同一个 Vercel 网址**，默认进入只读查看：概览 / 日程 / 剧本 / 资产 / 分镜 / Prompt。支持搜索、详情阅读和 Prompt 复制；默认无需登录。
4. 点击 **导入 Mac 项目快照**，选 JSON，核对项目、版本和时间后确认替换。取消不会覆盖当前快照。替换前额外保留一份本地恢复快照。
5. 手机显示**数据版本、项目最后更新时间、快照导出时间**，并明确“非实时同步”。Mac 新编辑不会自动出现在手机；需要再次导出/传输/导入。
6. 快照中的未结束计时被冻结为导出时累计时长，手机不自动计时；Mac 仍可继续原计时任务。
7. 小缩略图随 JSON 携带；没有缩略图、旧私有 Storage 引用或未连接的原图显示占位说明，不自动向云端索取或假装已同步。原始图片、视频、剪辑工程和 SSD 文件不包含在 JSON 中，需要自行备份。

只读模式可显式切回编辑工作台。Mac 顶部也有“手机查看模式”，便于预览。旧 JSON 可导入，缺少版本/时间时显示“未知”，不会伪造为实时数据。

## 本地保存与恢复

- 保留 `framework-studio-v1` 和每个账号原有的独立缓存键，不修改资产 ID、不自动改写素材引用。IndexedDB 提供完整项目镜像，localStorage 保持兼容；超出 localStorage 容量时仍尝试 IndexedDB，并显示保存结果。
- 多标签页计时使用 Web Locks 和独立持久化计时账本，拒绝同时开始两条。新版 Safari / Chrome / Edge 的 HTTPS 页面支持；旧浏览器不支持安全锁时禁用主动计时，仍可手动管理和导入快照。
- 工时按任务记录日期归入当天/本周。跨午夜的计时不会自动拆成多天，可结束后手动修改/补录。计时只在主动开始后运行；未暂停就关闭页面，重新打开仍按真实时间戳计算。
- 检测另一个标签页写入项目时，本页拒绝覆盖并提示先导出/刷新。建议 Mac 只保留一个编辑标签页。
- 缓存损坏时停止自动保存，保留原缓存；“导出项目”会导出原始异常缓存用于恢复排查，不能直接作为正常项目导入。
- 导入本地 JSON 需要确认，保留上次导入前快照，可在“项目与云端设置 → 导出上次导入前快照”取回。并非无限历史备份；导入前仍建议自己导出。
- 无痕窗口、清理网站数据、浏览器存储回收、设备损坏可能丢失本地数据；完成工作后导出 JSON 到安全位置。等待“已保存在此浏览器”后再关闭页面。不会因免费套餐自动升级。

## 云端边界

保留 Supabase 登录与手动同步，但今晚无需配置或使用。云端写入只接受轻量文字/索引，排除小缩略图、心情日记、计时账本；这些私人记录包含在本地 JSON 快照。剧本/视频/任务等元数据可沿用已有用户操作手动同步，未确认前不覆盖云端或本地。旧备份含 Base64 资产引用时，云端推送会被拒绝；本地阅读和备份不受影响，可未来手动处理。

`/api/agent` 在本免费 MVP 固定返回 503，即使旧部署残留 API Key 也不调用收费接口。没有公开项目接口、公开分享链接、新 Storage 上传或第三方分析服务。

## 验证

运行 `npm test`、`npm run test:auth:e2e`、`npm run build` 和 `npm run typecheck`。浏览器测试使用本地 Auth 替身，**不发真实邮件**；SQL/RLS 测试在 PGlite 内存中运行，不连生产数据库。覆盖计时/刷新/暂停/跨标签页、七资产与版本关联、剧本人工确认、视频 Prompt、完整快照、手机确认导入/取消/刷新/搜索/复制与缓存异常保护。

浏览器自动化是 Chromium 的桌面和手机尺寸，真实 Mac Safari 与 iPhone Safari 需要部署后用备份副本验收。不保证浏览器自动永久保留数据，不把快照当实时云同步。
