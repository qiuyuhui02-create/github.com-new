# 第三阶段：多模型剧本对比（默认关闭）

无需购买任何付费服务。未配置的提供商显示“未连接”，不返回模拟回复。UI 位于“剧本工作台 → 场景 → 多 AI 对比”。现有 AI Agent 的本地规则分析继续独立标注；多模型接口不使用该规则引擎冒充模型。

## 安全与费用边界

- 每个提供商都需要**服务端** Key、模型 ID 和显式启用开关。密钥不得用 NEXT_PUBLIC 前缀，不写入 Git，也不通过状态接口返回。
- OpenRouter 强制模型 ID 以 `:free` 结尾，发送最高 prompt/completion 价格 0、关闭供应商 fallback；不接受客户端传入任意模型或 URL。
- Gemini 与豆包的免费/试用资格、地区与余额取决于账户，API 端点本身**不能证明调用免费**。本程序没有余额查询、购买、充值或付费切换逻辑。管理员必须先在服务商控制台确认免费资格，并使用无付费结算能力的项目/凭据，或设置足够严格的供应商侧费用硬限制。无法保证时保持关闭。
- 免费确认开关只是管理员声明，不是程序对服务商计费的验证。额度耗尽/429 时显示失败，不重试，不换模型，不充值。免费额度不是无限额度，也不保证随时可用。
- 新比较接口不读取或自动启用旧版 `ENABLE_PAID_AI`。旧 OpenAI Agent 付费接口仍默认关闭。
- 每次用户发起请求前确认要将**当前场景工作稿及修改要求**发送给所选外部服务商；不会上传本地图片、视频或整个项目。
- 必须先通过 Supabase 身份验证，并经数据库原子计数：每用户每天（Asia/Shanghai）最多 5 次比较，每次最多 3 个模型。失败请求也会消耗一次，避免无限重试。若配额 SQL 未配置，接口拒绝调用任何模型。
- 用户切换场景会中止浏览器等待，但已发送的服务商调用可能仍完成并消耗额度；不要据此重复提交。

## 可选配置步骤

不使用 AI 时无需执行本节，剧本手动编辑与定稿功能完整可用。

1. 在 Supabase SQL Editor 执行 `supabase/ai-quota.sql`。新增独立的轻量计数表和函数，不修改/删除 `studio_projects`。
2. 仅在你确认有免费/试用资格后，在 Vercel 对应环境设置下面的服务端变量。
3. 启用一个提供商即可使用；并排对比需要至少两个。重新部署后检查面板状态。
4. 本次开发未申请账号、未设置真实模型 Key、未执行真实模型 API 调用。测试使用依赖注入或浏览器拦截的替身响应，且不会出现在产品默认数据里。

### Gemini 免费层（需账户资格确认）

```dotenv
GEMINI_API_KEY=你的服务端Key
GEMINI_MODEL=你账户当前可用且支持免费层的模型ID
GEMINI_COMPARE_ENABLED=true
GEMINI_FREE_TIER_CONFIRMED=true
```

从 Google AI Studio / Gemini 控制台确认模型、地区、配额及计费状态。模型 ID 只填名称，不填 `models/` 前缀。不硬编码某个“永远免费”的型号，不自动升级替代型号。

### OpenRouter 免费模型

```dotenv
OPENROUTER_API_KEY=你的服务端Key
OPENROUTER_MODEL=你选择的具体模型:free
OPENROUTER_COMPARE_ENABLED=true
```

从 OpenRouter 当前模型列表选实际存在的 `:free` 模型，不使用付费模型 ID。可使用没有付费余额/结算能力的独立凭据，并在平台限制可用模型。即使免费，也可能有日限额、隐私政策或数据保留要求，请按平台信息确认。

### 豆包试用 API（只有符合条件才启用）

```dotenv
DOUBAO_API_KEY=你的服务端Key
DOUBAO_MODEL=你账户当前可用的模型或推理接入点ID
DOUBAO_COMPARE_ENABLED=true
DOUBAO_TRIAL_CONFIRMED=true
```

只有火山方舟账号确实具备对应模型试用额度，且已配置不会超额转付费的限制时才启用。没有资格保持 false。适配器使用北京区固定 OpenAI 兼容端点，其他地区/协议未自动适配。

## 对比与采用

1. 选择当前场景，输入统一修改要求，勾选已连接且获准的模型，确认发送。
2. 服务端构造一次统一输入，所有提供商接收相同文本与要求；返回输入 SHA-256，便于验证同稿对比。
3. 成功响应并排显示并保存为独立模型版本（含提供商/模型、时间、输入 hash、来源工作稿 revision 与比较批次）。失败只显示错误，不填充假内容。
4. 每场最多 30 个模型版本，不静默裁剪旧版本；到达上限先导出备份、拆分项目。对比输入上限 2 万字，要求 2000 字，输出最多 4096 tokens。截断输出会报告失败，不当作完整版本保存。
5. 可将整版载入工作稿（原工作稿进入历史）、整版加入人工候选，或逐段采用到候选。之后可继续逐句确认、手动编辑合并。
6. 正式定稿不因模型响应或采用工作稿而改变。必须到“修改与确认”点击人工确认定稿，已有定稿保留历史。
7. 对比结果先保存在本地缓存；需手动推送云端，或导出 JSON 做 Mac 备份。服务端模型调用不直接写项目表。

## 扩展接口

- 公共类型：`lib/ai/types.ts`，不含密钥。
- 服务端注册与适配器：`lib/ai/providers.ts`，固定服务商地址，统一输入、超时、输出限制和无回退策略。
- Next.js 路由：`app/api/script/compare/route.ts`，验证登录、来源、输入与数据库配额。
- UI：`components/multi-ai.tsx`，仅获取公共状态并提交当前工作稿，不导入服务端适配器。

当前没有在线验证供应商最新模型可用性，型号必须由管理员根据账户实际列表填写。部署环境也需要允许访问所选提供商；连接失败时功能会明确报错，不替代为模拟文本。
