# aikari

清新明亮的免费个人 AI 电影制作工作室。基于现有 Next.js 16 / React 19 / TypeScript / Tailwind CSS 项目继续迭代，兼容 Vercel Hobby。

**Mac Safari 编辑，手机只读查看项目快照；所有核心功能无需登录。** Windows 可完全离线制作，素材由你自行传输。网站不生成或上传原始图片、视频，不调用付费 API。

## 手动创作流程

剧本支持全文导入并人工核对拆分预览，或从空白创建；自由章节目录支持重命名、拖动、复制和安全删除，右侧宽幅编写、对比与定稿分开显示。ChatGPT、Gemini、Claude 通过平台标签切换大编辑器，支持单栏/双栏和专注模式；内容仅手动粘贴，选段可插入或替换明确目标，整章可一次确认移入回收站并恢复；统一修改要求可连同本场剧本复制到外部工具。候选选段由你明确采用到人工工作稿，可撤销，最终定稿独立确认。分镜支持手动建镜头与九宫格排序，视频任务的首帧/尾帧/分镜图/人物图独立保存并进入版本历史。详见 [手动工作流与兼容说明](docs/MANUAL_WORKFLOW.md)。

本版本从已合并 PR #8 的 main 开发，不合并或启用 PR #9，不依赖任何 AI API。

## 当前使用与部署

请先读 **[今晚 MVP / Mac → 手机快照指南](docs/TONIGHT_MVP.md)**。不需要执行 SQL、设置 SMTP、新增环境变量或购买服务。保留现有 Vercel 项目和正式网址。

五个核心模块：

1. 创作日程：月历、任务与地点、截止倒计时、主动工时计时/补录、私人心情与日记。
2. 剧本工作台：中日文场景、只读原稿、三个手动 AI 结果栏、逐段采用与人工定稿、历史版本。
3. 资产库：人物、场景、道具、服装、其他；小缩略图、状态、版本与素材索引。
4. 分镜工作台：镜号、参考图、构图、景别、时长、运动、对白/声音及关联资产。
5. 视频提示词与制作：逐镜 Prompt、复制、首尾帧/参考清单、模型、生成版本与修改意见。

另保留本地素材索引工具、Prompt 中心和免费本地制作检查。

## 本地预览

Node.js 20.9+（推荐 Node 22/24）：

```bash
npm ci
npm run dev
```

打开 http://localhost:3000 。新浏览器显示 6 个示例资产，已有缓存优先读取，**不会重置或替换用户的 7 个资产**。预览域名与正式域名存储独立，请使用 JSON 副本验收。

## 保存与手机查看

更改保存至当前浏览器，IndexedDB 与兼容 localStorage 缓存共同持久化；等待“已保存在此浏览器”后再关闭。浏览器缓存不是永久备份，请定期点击“导出项目”。

JSON 快照包含剧本、日程、私人心情日记、任务、工时、资产/版本、分镜、Prompt 和小缩略图，不包含原始媒体。手机打开同一个网站，点击“导入 Mac 项目快照”并确认；显示版本和时间，**不实时同步**。没有随快照携带的图片显示占位说明。

## 验证

```bash
npm test
npm run test:auth:e2e
npm run build
npm run typecheck
```

`test:auth:e2e` 自动启动本地 Auth 替身和 Next 服务，所有邮件/认证请求只访问本地回环地址，不发送真实邮件；默认使用 `/usr/bin/chromium`，可用 `CHROMIUM_PATH` 指定已安装的 Chromium。SQL/RLS 回归使用本地 PGlite 内存数据库，不访问生产数据。

自动化覆盖桌面与手机尺寸。真实 Safari、iPhone 和用户自己的七资产备份需部署后低风险验收。

## 保留的可选云端功能

沿用已合并 PR #6/#7 的登录和 Supabase 手动同步。今晚无需登录，也不排查邮件配额；不需要修改数据库。旧配置说明仅供后续维护参考：[密码登录](docs/PASSWORD_LOGIN.md)、[邮箱回调](docs/AUTH_LOGIN_FIX.md)、[云端配置](docs/SUPABASE_SETUP.md)。

云端只接收文字与索引；心情日记、计时账本和缩略图留在本地/JSON。项目不会公开分享或暴露到无需身份验证的数据接口。`/api/agent` 在此 MVP 固定禁用，即使旧部署残留 API Key 也不会调用收费接口。

已有素材目录说明见 [LOCAL_MEDIA.md](docs/LOCAL_MEDIA.md)，剧本历史设计见 [SCREENPLAY.md](docs/SCREENPLAY.md)。历史 SQL 文件只是保留供维护，不代表需要在本次上线执行。
